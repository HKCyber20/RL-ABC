# VLA（Vision-Language-Action）12 周学习计划

> 目标：在仿真环境中完成一个“根据自然语言指令抓取并放置物体”的 VLA 原型，并具备阅读、运行和小规模微调开源 VLA 的能力。

## 0. 学习目标与范围

### 最终项目

实现并评估下列闭环策略：

```text
相机图像 + 语言指令 + 机器人状态 → 下一段机器人动作
```

任务示例：`把红色方块放进蓝色盒子。`

最终应交付：

- 可复现的仿真环境配置与数据集；
- 一个语言条件行为克隆（BC）策略；
- 至少两组泛化评估：未见目标位置、未见颜色或背景；
- 实验记录：成功率、失败案例与改进方向；
- 对 RT-2、Open X-Embodiment、OpenVLA 的结构性理解。

### 暂不纳入第一阶段

- 从零训练 7B 级 VLA；
- 真机部署；
- 多机器人跨本体预训练；
- 端到端强化学习。

这些方向需要大量数据、算力或硬件调试，适合作为原型完成后的下一步。

### 第 1 周：Transformer 与动作预测的共同语言

> 执行日期：2026-08-31 至 2026-09-06。建议总投入 9–11 小时；工作日每天 1–1.5 小时，周末每天 2–3 小时。

#### 本周目标

完成本周后，应当能够：

1. 说明 token、embedding、位置编码、Q/K/V 分别是什么；
2. 根据张量形状手算一遍 scaled dot-product attention；
3. 区分 self-attention、cross-attention 和 causal self-attention；
4. 用 PyTorch 实现单头 attention，并验证输出维度和权重和为 1；
5. 画出一个最小 VLA 数据流：`图像 + 指令 + 状态 → 动作`。

本周只学习 VLA 必需的 Transformer 概念，不要求训练真正的机器人策略。

#### 本周核心公式

\[
Q=X_QW_Q,\qquad K=X_KW_K,\qquad V=X_VW_V
\]

\[
A=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right),\qquad O=AV
\]

在 self-attention 中，`X_Q`、`X_K`、`X_V` 来自同一个序列；在 VLA 的一种 cross-attention 结构中，可以令文本产生 `Q`、图像 patch 产生 `K/V`。

#### Day 3（9 月 2 日）：从数值理解 Q、K、V

**时间：90 分钟**

学习：

- `Q` 表示当前位置要查找什么；
- `K` 表示每个 token 可被怎样匹配；
- `V` 表示匹配后真正取回的信息；
- 点积、缩放和 softmax 各自的作用。

动手：

- 使用 3 个 token、每个 token 4 维的极小矩阵，完成：

  ```python
  scores = Q @ K.transpose(-2, -1) / sqrt(d_k)
  weights = softmax(scores, dim=-1)
  output = weights @ V
  ```

- 打印 `scores`、`weights` 和 `output`；验证每一行 `weights` 的和约等于 1。
- 修改某个 `K`，观察对应注意力权重如何变化。

当天产出：`scaled_dot_product_attention` 的最小实现，以及一段对输出结果的解释。

#### Day 4（9 月 3 日）：Self-Attention、Mask 与 Multi-Head

**时间：90 分钟**

学习：

- self-attention 为什么可以让一个 token 汇总整个序列的信息；
- causal mask 为什么禁止语言模型看到未来 token；
- 多头注意力为什么可以学习不同的匹配关系。

动手：

- 构造一个 `4×4` causal mask，确认第 2 个位置不能访问第 3、4 个位置；
- 使用 `torch.nn.MultiheadAttention` 运行一个小样例；
- 记录以下形状变化：

  ```text
  输入: [B, N, d_model]
  分头: [B, heads, N, d_head]
  权重: [B, heads, N, N]
  输出: [B, N, d_model]
  ```

当天产出：一张 self-attention 形状流转图。

### 第 3 周：行为克隆（BC）

**学习内容**

- 专家轨迹：`(observation_t, action_t)`。
- 行为克隆损失：

  \[
  \mathcal{L}_{BC}=\|a_t^{pred}-a_t^{demo}\|^2

- 分布偏移：为什么离线 loss 很低，rollout 仍可能失败。

**动手任务**

## 6. 关键原则

- **先做闭环，再追求大模型。** 训练集准确率不等于机器人任务成功。
- **先统一动作与坐标系，再调模型。** 数据动作定义错误时，换模型通常无效。
- **先复现小任务，再微调 OpenVLA。** 不要把数据、环境、模型和真机问题同时引入。
- **实验必须记录成功率和失败类型。** 只有 loss 无法定位 VLA 的实际瓶颈。

## 1. 今日目标与预计时间

预计 120 分钟。构造受控场景与反事实输入，验证策略输出是否随指令目标、视觉目标位置和关键 token 发生有方向的变化。

## 2. 这在 VLA 中的作用

Grounding 是把词语绑定到可见实体与控制目标。训练 loss、注意力热图和“偶尔成功”都不足以证明绑定；反事实测试能直接询问：只改变语义，决策是否按预期改变？

## 3. 核心概念与探针矩阵

控制变量矩阵：

```text
固定场景，换指令        → 应换目标
固定指令，交换物体位置  → 动作方向应跟随目标位置
删除关键颜色 token      → 置信/行为应退化或变得不确定
换无关措辞              → 语义等价时行为应近似稳定
打乱图像—文本配对       → 成功率应下降
```

首步方向一致率可定义为：

\[
DAcc=\frac1N\sum_i \mathbb{1}[\langle \hat{\Delta p}_i,p^*_{i}-p^{ee}_i\rangle>0].
\]

## 4. 分步学习

1. 生成至少 8 个双目标场景，目标左右位置随机而颜色身份独立。
2. 每个场景生成指向不同目标的成对指令，共至少 16 个样本。
3. 计算预测动作、目标距离变化或首步方向一致率。
4. 交换目标位置但保留指令；删除/替换关键 token；加入等价模板。
5. 若有 attention，记录热图，但以动作/目标选择作为主要证据。
6. 把失败分为未用语言、未定位视觉、错绑定、动作执行异常。

## 5. 必做作业

- 提交探针数据生成规则和至少 16 个成对样本清单。
- 完成上述前 5 类反事实中至少 4 类，输出逐样本结果和汇总。
- 找出至少 2 个失败样本，给出可证伪的原因假设与下一步实验。

## 6. 输入、预期输出与验证

输入：Day 3/4 checkpoint、同图冲突指令、交换位置场景、关键 token 消融、等价模板。

预期输出：合格策略应在目标变化时有方向性响应，在语义等价时相对稳定；实际模型可能失败，必须原样报告。

验证：目标位置/颜色独立随机；指标代码用几何真值而非人工挑图；对随机策略计算参考水平；检查指令变化外其他输入逐元素相同。

## 8. 评分与验收

- 成对场景控制严格：20 分。
- 至少四类反事实：25 分。
- 几何/动作指标可复算：20 分。
- 不把 attention 当唯一证据：15 分。
- 失败假设、自测与复现：20 分。

总分 100，80 分通过；只展示成功样本、场景与指令同时变化或以 attention 热图代替行为验证时不通过。

## 9. 常见错误与排查

| 错误 | 排查 |
|---|---|
| 颜色与左右固定绑定 | 每种颜色均出现在左右两侧 |
| 首步很小导致符号不稳 | 同时报投影值/范数并设最小动作阈值 |
| 等价模板含 OOV | 先区分 tokenizer OOV 与语义鲁棒性 |
| 打乱配对仍成功 | 检查任务是否可忽略语言或 success 判定过松 |

## 10. 时间不足时的最低完成线

用 4 个 synthetic 双目标场景做同图换指令、交换位置、关键 token 替换三类探针，并报告 8 对样本的逐项结果。

## 11. 可选提高

做梯度/遮挡敏感性与行为结果对照；构造三目标场景；测等价中文措辞的鲁棒性。

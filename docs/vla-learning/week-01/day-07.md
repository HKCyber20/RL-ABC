## 1. 今日目标与预计时间

预计 2–3 小时。闭卷复述本周概念，整合并复跑 toy VLA，形成第一份可验证周项目报告；根据证据判断通过或生成补救任务。

## 2. 今日知识点及其在 VLA 中的作用

综合链路是：原始输入 token 化/投影并加入位置，Q/K/V 计算模态内或模态间读取，融合表示结合机器人状态预测动作，动作进入环境形成下一观测。周验收关注能否同时解释语义、形状、梯度和闭环，而非背单个定义。

## 3. 必要概念、公式、形状与数据流

周项目固定接口：

```text
image [B,16,32]
text  [B, 6,32] -> text queries image -> fused [B,6,32]
state [B,8]                         -> prediction [B,7]
prediction + target -> MSE -> backward
```

注意力核心：`softmax(QK^T/sqrt(d_k), dim=-1)V`；闭环核心：`(o_t,l,s_t)->a_t->env->(o_{t+1},s_{t+1})`。

## 6. 输入、预期输出与验证方法

- 输入：Day 6 固定接口，随机种子写入报告。
- 预期：独立运行退出成功；输出 `[B,7]`；权重最后一维和约 1；loss 和梯度有限；step 后参数变化。
- 验证：关闭并重启运行环境后全量执行；报告命令、环境和日志。随机数值只记录实际结果。

低资源替代：缩小到 `B=2,D=8,H=2,P=4,L=3`，验收性质不变。

## 8. 评分与验收标准

100 分，80 分通过。周测 30；独立复跑 15；跨模态方向和形状 15；loss/backward/step 20；闭环图 10；错误分析 10。周测至少 20/30，且输出形状、跨模态方向、闭环反馈三项必须正确。没有实际运行环境时最高记“理论通过”，补运行后才能勾选整周。

## 9. 常见错误与排查

- notebook 顺序依赖：从“重启并全部运行”暴露缺失变量。
- 日志只有 loss：补形状、权重和梯度证据。
- 报告把 toy 网络称为真实 VLA：明确其无真实视觉编码器、轨迹数据与环境执行。
- 修改代码后未更新报告：确保日志对应最终版本。

## 10. 时间不足时的最低完成线

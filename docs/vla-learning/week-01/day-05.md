## 1. 今日目标与预计时间

预计 90–120 分钟。能根据 Q 与 K/V 的来源判断 cross-attention 方向，推导文本读取图像的权重形状，并通过可控小实验观察查询改变导致的权重变化。

## 2. 今日知识点及其在 VLA 中的作用

Cross-attention 的 Q 与 K/V 来自不同序列。令文本为 Q、图像 patch 为 K/V，含义是“每个文本位置从图像区域取回信息”；令动作 query 为 Q，则含义是“每个待预测动作槽读取多模态上下文”。方向决定输出序列长度和每个输出位置代表什么。

## 3. 必要概念、公式、形状与数据流

文本读取图像：

```text
text [B,L,D]  -> Q [B,H,L,Dh]
image [B,P,D] -> K,V [B,H,P,Dh]
weights [B,H,L,P]
output  [B,L,D]
```

例如 `B=2,H=4,L=6,P=16,D=32,Dh=8`，权重为 `[2,4,6,16]`。交换方向后，图像为 Q，权重变成 `[2,4,16,6]`，输出长度也变为 16。

Cross-attention 只完成条件读取；机器人状态可经 MLP 变为状态 token，或在池化后拼接。两者都是设计选择，必须写明。

## 4. 分步骤学习

1. 为“红色目标”和“蓝色容器”各设计一个二维 query。
2. 为红块、蓝盒、机械臂、背景设计四个二维 key/value。
3. 计算两个 query 对四个 patch 的权重并制表。
4. 写出真实规模 `L=16,P=196,D=256,H=8` 的形状。
5. 解释为何注意力权重是读取比例但不能单独证明模型因果依据。

## 5. 必做作业

构造 `B=1,L=2,P=4,D=4` 的可控 cross-attention。两个文本 query 分别代表“红色目标”“蓝色容器”，四个 patch 分别代表红块、蓝盒、夹爪、背景。提交两行权重表，并改变 query 次序，验证输出次序相应改变而 patch 序列不变。再写一段话说明若把图像当 Q，任务语义发生什么变化。

## 6. 输入、预期输出与验证方法

- 输入：text `[1,2,4]`、image `[1,4,4]`；可以手工设置或通过线性投影得到 Q/K/V。
- 预期：weights `[1,2,4]`、output `[1,2,4]`；两个 query 的权重分布不完全相同。
- 验证：每行权重和为 1；交换 query 后两行结果同步交换；不得声称某 patch 一定最高，除非实际数值证据支持。

## 8. 评分与验收标准

100 分，80 分通过：方向语义 25；形状 20；实验 25；验证 15；解释边界 15。将权重形状写成 `[B,P,L]` 却声称文本为 Q，或混淆输出长度，关键项失败。

## 9. 常见错误与排查

- Q/K 特征维不同：先分别投影到相同 `D_h`。
- K/V patch 次序不一致：两者必须对应同一视觉位置。
- 只交换标签未交换 query 数值：记录实际张量。
- 把高权重直接称作可解释性结论：还需干预、梯度或消融证据。

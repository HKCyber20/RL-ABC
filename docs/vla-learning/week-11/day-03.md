## 1. 今日目标与预计时间

预计：**110–160 分钟**。

- 设计空间上严格分离的 train/test 位置。
- 控制目标距离、可达性和相机可见性。
- 生成位置热图/分区表和失败证据。

## 2. 今日知识点及其在 VLA 中的作用

未见位置测试策略是否学到视觉闭环与空间关系，而不是记忆固定抓取点；同时要防止不可达位置把控制限制误判成模型泛化失败。

## 3. 必要概念、公式、形状与数据流

- 用 workspace 坐标 `(x,y)` 定义区域；训练/测试之间设置 buffer margin，避免连续空间边界近邻泄漏。
- 每个位置记录 reachability、visibility、初始末端距离、遮挡与目标大小；这些是重要混杂变量。
- 主指标按位置 cell 报成功率与 CI；附最差 cell、到训练集最近距离和失败阶段。

## 4. 分步骤学习内容

1. 画工作空间网格，标 train/validation/test 与 buffer。
2. 用距离规则程序化分配 split。
3. 为每格平衡 seed、物体和指令。
4. 生成 per-cell 表或 ASCII 热图，分析边缘/遮挡效应。

## 5. 必做作业

- 提交 position_split.json 与 unseen_position_report.md。
- 实现 split validator，拒绝训练与测试距离小于 margin 的点。
- 用实际或 mock 记录计算至少 6 个 cell 的成功率。

## 6. 作业输入、预期输出与验证方法

| 项目 | 内容 |
|---|---|
| 输入 | 二维 workspace `x,y∈[-0.3,0.3] m`，margin 0.05 m；每个 cell 至少记录 3 seed。 |
| 预期输出 | train/test 不重叠且满足 margin；报告不把不可达点纳入主要模型结论，另行统计。 |
| 验证方法 | 计算 train-test 最小欧氏距离。；检查每个 test 点相机可见且在控制器安全范围。；按最近训练距离排序失败率。 |

若未运行真实仿真，所有 mock 数字必须显式标为“仅验证分析管线”。

## 8. 评分与验收标准

| 评分项 | 分值 | 得分条件 |
|---|---:|---|
| 协议、公式与统计 | 20 | split、分母、假设和公式准确 |
| 代码/数据/报告产物 | 25 | schema 完整，结果可回溯 episode |
| 验证与重算证据 | 25 | 有命令、输出、边界测试或人工复核 |
| 泛化与失败分析 | 20 | 控制混杂，区分观察/推断/假设 |
| 复盘与自测 | 10 | 诚实说明限制并答对自测 |
| **总分** | **100** | **80 分通过** |

硬门槛：位置 split 仅用随机采样导致近邻泄漏，或不可达点未标记，不得通过。

## 9. 常见错误与排查提示

- 像素位置不同但世界坐标相同。
- 改变位置时同时改变背景。
- 只报平均而隐藏一个完全失败区域。
- 先检查 manifest 行数、唯一 episode id、seed/condition 分布、缺失值和分母，再解释模型。
- 不得将 mock 记录、预期 CI 或未运行的 rollout 写成真实性能。

## 10. 时间不足时的最低完成线

4 个 train、4 个 test 点，margin 检查和 per-point 表。 最低线仍需固定协议并提交可复核证据。

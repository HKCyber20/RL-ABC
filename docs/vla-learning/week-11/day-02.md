## 2. 今日知识点及其在 VLA 中的作用

单次 rollout 的成功率波动很大；置信区间和 seed 明细让你判断差异是否稳定，而不是只比较两个百分点。

## 3. 必要概念、公式、形状与数据流

- 对 k/n 的 Wilson 区间，令 z=1.96，中心与半宽由 `(p̂+z²/(2n) ± z*sqrt(p̂(1-p̂)/n+z²/(4n²)))/(1+z²/n)` 给出。
- 若多个 episode 共享 seed/场景，独立同分布假设可能不成立；同时报告 per-seed 成功率，并可按 seed bootstrap。
- 置信区间不是“真实成功率有 95% 概率在区间内”的贝叶斯陈述；本课关注可重复汇报而非过度解读显著性。

## 4. 分步骤学习内容

1. 手算 k=8,n=10 的 p̂，并用脚本算 Wilson 区间。
2. 构造 3 seeds×10 episodes，计算 pooled 与 per-seed 表。
3. 设计 seed-level bootstrap 的伪代码。
4. 比较两个策略时同时查看点估计、区间、配对条件和最差 seed。

## 9. 常见错误与排查提示

- 把三 seed 的标准差当 episode-level CI。
- 整数除法导致 p̂ 为 0。
- 对缺失 episode 静默补失败/成功。
- 先检查 manifest 行数、唯一 episode id、seed/condition 分布、缺失值和分母，再解释模型。
- 不得将 mock 记录、预期 CI 或未运行的 rollout 写成真实性能。

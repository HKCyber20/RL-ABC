[返回课程总入口](../README.md) · [Goal 进度](../PROGRESS.md) · [Notebook 格式说明](../WORKBOOK_FORMAT.md)

## 使用方法

1. 从 [Week 01 / Day 01](week-01/day-01.ipynb) 开始。
2. 使用 JupyterLab、VS Code Notebook 或其他兼容编辑器打开 ipynb 文件。
3. 双击 Markdown 作答单元，替换方括号中的占位文字。
4. 代码日从上到下运行所有 Code 单元并保留输出。
5. 保存后把 Notebook 路径发到学习对话；不要自行修改教练验收状态或 PROGRESS.md。
6. 当前环境尚未检测到 Jupyter 运行依赖，因此生成的 Notebook 仅完成结构验证，尚未执行。

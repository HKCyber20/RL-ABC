## 使用规则

1. 从 [Week 01 / Day 01 作业](week-01/day-01.md) 开始。
2. 在当天文件中保留题目，直接填写答案、代码路径、命令、日志和自测。
3. 未执行的输出标记为“预期结果”，不要写成实际结果。
4. 不要填写“教练验收区”，也不要自行勾选 `PROGRESS.md`。
5. 将填写后的文件路径发到学习对话；教练依据当天 rubric 验收。
6. 只有通过验收后，教练才会更新进度并告知下一份作业。

## 4. 输入、预期输出与验证

### 课程要求

输入：固定 `seed=7`；动作序列为 10 个 `[0.01, 0.00, 0]`；Mock 边界可设为 `[-1,1]`。

## 9. 常见错误、最低完成线与可选提高

### 常见错误与排查

| 错误 | 排查 |
|---|---|
| 把“文档支持”当成本机可运行 | 只记录实际 import 与 smoke test 证据 |
| 两次 seed 仍不一致 | 同时固定环境、NumPy 和动作序列，检查渲染噪声 |
| `step` 返回结构混乱 | 用命名字段或固定五元组并写类型断言 |
| Mock 与真实平台接口分叉 | 用 adapter 保持同一 observation/action schema |

### 时间不足时的最低完成线

完成平台比较与 NumPy Mock 的两次确定性 reset/step；保留命令、完整日志和 3 个 shape 断言。

### 可选提高任务

为两个候选平台写 adapter 接口草图；估算 1000 条 200 步 RGB 轨迹的存储量；给 Mock 增加碰撞或动作延迟。

## 9. 常见错误、最低完成线与可选提高

### 常见错误与排查

- 忽略 checkpoint 缓存与数据集磁盘。
- 混用 GB/GiB 而不标单位。
- 环境文件只有包名没有版本/commit。
- 先打印输入 mode/shape、processor keys、model revision、action stats key 与 action shape，再排查数值。
- 不得声称执行过未实际运行的安装、推理或训练。

### 时间不足时的最低完成线

完成 fp16/fp32 下界计算、10 项检查和 mock 路径。 最低线也要提交实际证据或逐项“预期”标记。

### 可选提高任务

加入量化权重的理论下界，同时列出精度/算子兼容风险。

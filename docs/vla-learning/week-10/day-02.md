## 2. 今日知识点及其在 VLA 中的作用

7B 级 VLA 的失败常发生在模型运行前；资源规划避免长下载、依赖冲突和显存不足，并保证没有高端 GPU 也能继续学习。

## 3. 必要概念、公式、形状与数据流

- 粗略权重内存下界：参数量 × 每参数字节；训练还需梯度、优化器状态、激活和通信缓冲，不能用权重大小代表总显存。
- 环境记录至少含 OS、Python、PyTorch/CUDA、transformers、tokenizers、timm、flash-attn/替代、GPU/VRAM、磁盘、commit 和模型 revision。
- 三档路径：真实 checkpoint 推理；小 batch/adapter dry-run；纯 CPU mock 静态与接口测试。安装/下载是有成本写操作，课程不自动执行。

## 4. 分步骤学习内容

1. 用 7B 参数分别估算 fp32/fp16 权重理论下界，并注明不含其他开销。
2. 检查当前机器可用环境的方法写成命令清单，但本课不要求执行联网命令。
3. 制定 go/no-go 阈值：磁盘、显存、网络、时间与许可。
4. 为无 GPU 方案写 mock 验收映射，说明它能/不能证明什么。

## 6. 作业输入、预期输出与验证方法

| 项目 | 内容 |
|---|---|
| 输入 | 假设模型约 7B 参数；本机信息若未实测则写“未知，需命令确认”。 |

## 8. 评分与验收标准

| 评分项 | 分值 | 得分条件 |
|---|---:|---|
| 架构/公式/shape | 20 | 数据流准确，稳定概念与版本项分开 |
| 接口或配置产物 | 25 | 输入输出、异常、revision 与 key 完整 |
| 验证证据 | 25 | 命令/断言/输出可复核，mock 与 real 明确区分 |
| 动作与安全分析 | 20 | 反归一化、单位、frame、范围或 controller 风险正确 |
| 复盘与自测 | 10 | 能定位失败并回答自测 |
| **总分** | **100** | **80 分通过** |

硬门槛：未经证据给出“本机一定能跑”，或把权重下界当作训练显存需求，不得通过。

## 9. 常见错误与排查提示

- 忽略 checkpoint 缓存与数据集磁盘。
- 混用 GB/GiB 而不标单位。
- 环境文件只有包名没有版本/commit。
- 先打印输入 mode/shape、processor keys、model revision、action stats key 与 action shape，再排查数值。
- 不得声称执行过未实际运行的安装、推理或训练。

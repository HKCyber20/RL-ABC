## 本周核心能力

本周将第 1 周的 `[B,7]` 抽象动作变成无歧义的机器人命令：明确参考坐标系、位置与姿态、齐次变换、正/逆运动学、绝对/增量动作、频率与闭环。它保障总 Goal 中的数据构造和策略执行不会因坐标、单位或时间定义错误而失效。

## 前置知识

- 第 1 周的 VLA 闭环和张量形状；
- 向量、矩阵乘法与三角函数基础；
- Python/NumPy 有助于验证，但所有核心练习可用纸笔完成；
- 不需要真实机械臂、仿真器、GPU 或网络下载。

## 本周代码与实验产物

- 一张机器人/基座/相机/末端/物体坐标系图；
- 齐次变换组合、求逆和点变换验证代码；
- 旋转表示转换与合法性检查表；
- 二连杆 FK/IK 数值实验；
- 一份 7 维动作空间规范；
- 闭环频率与延迟实验；
- 可执行的动作接口验证器和周报告。

## 必做与可选任务

必做聚焦坐标约定、数值验证和错误分析；可选任务涉及 Jacobian、SLERP 等。没有仿真器时使用二维机械臂和纯 NumPy；没有 NumPy 时用给定 2D/90° 案例手算。不要为了本周任务安装大型仿真平台。

## 最低完成线

- 能写出 `T^A_B` 的方向含义并正确组合两次变换；
- 能检查旋转矩阵、四元数是否有效；
- 能解释 FK 与 IK 的输入输出和多解性；
- 动作规范必须包含坐标系、单位、旋转、夹爪、频率、边界；
- 能说明闭环频率与延迟如何改变实际位移和稳定性。

## 周末测验、周项目与通过标准

Day 7 用 30 分闭卷测验和 70 分动作接口项目验收。总分 80/100 通过；其中坐标变换方向、动作单位、夹爪语义、频率四个关键字段必须正确。周项目的数值结果必须来自实际执行或清晰手算，不得当作已经连接真实机器人。

预计 100–140 分钟。理解 FK 从关节状态求末端位姿、IK 从目标位姿求关节解；用二维二连杆完成可达性、多解和数值验证。

## 2. 今日知识点及其在 VLA 中的作用

VLA 可以输出关节命令，也可输出末端笛卡尔目标。后一种通常需 IK 转换给低层控制器。模型即使预测了合理末端目标，也可能因超出工作空间、关节限位或 IK 分支跳变而执行失败，因此必须区分策略失败与控制/求解失败。

## 3. 必要概念、公式、形状与数据流

二维二连杆长度 `l1,l2`、角度 `q1,q2`：

\[
x=l_1\cos q_1+l_2\cos(q_1+q_2)
\]
\[
y=l_1\sin q_1+l_2\sin(q_1+q_2)
\]

IK 中：

\[
\cos q_2=\frac{x^2+y^2-l_1^2-l_2^2}{2l_1l_2}
\]

`q2` 通常有正负两支（肘上/肘下）。可达条件 `|l1-l2| <= sqrt(x²+y²) <= l1+l2`。一般 6/7 轴机械臂还涉及冗余、碰撞和关节限位。

## 4. 分步骤学习

1. 画二连杆并从几何推导 FK。
2. 对三组关节角计算末端点。
3. 对可达目标求两个 IK 分支。
4. 将 IK 解送回 FK，检查位置误差。
5. 测试一个不可达点和接近奇异位置的点。

## 5. 必做作业

实现 `fk_2link(q,l)` 与 `ik_2link(xy,l)`，令 `l1=l2=1`，测试目标 `[1,1]`、`[2.1,0]`、`[1.99,0]`。对可达目标返回所有有效分支并做 FK 回代；不可达点必须显式返回状态而非 NaN 冒充结果。说明实际 VLA 系统应在哪一层处理 IK 失败。

## 6. 输入、预期输出与验证方法

- 输入：上述长度与三目标。
- 预期：`[1,1]` 有可达解且通常存在两个构型；`[2.1,0]` 不可达；`[1.99,0]` 接近伸直构型，对小扰动更敏感。
- 验证：每个解经 FK 的欧氏误差 `<1e-6`（手算可放宽到 `1e-3`）；角度单位统一；非法 `acos` 输入在容差内 clip 并记录。

低资源替代：手算 `[1,1]` 的一个或两个解并回代。

## 7. 提交内容与固定格式

固定包含：`FK/IK 输入输出对照`、`公式`、`代码或手算`、`三目标结果`、`回代误差`、`IK 失败归因`、`投入分钟数`。

## 8. 评分与验收标准

100 分，80 分通过：FK 20；IK 与分支 25；可达性 15；回代 20；VLA/控制边界分析 20。不可达点静默产出 NaN、只返回一个分支却声称唯一、未回代验证均为关键失败。

## 9. 常见错误与排查

- 角度度/弧度混用：打印已知 `q=0` 结果。
- 浮点误差令 `acos` 略超 [-1,1]：先判断可达，再在容差范围 clip。
- 只比关节角：IK 多解时应比较 FK 末端误差。
- 将 IK 失败算作感知失败：日志需单独分类。

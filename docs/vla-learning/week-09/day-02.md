## 1. 今日目标与预计时间

预计：**90–120 分钟**。

- 解释 RT-2 中“动作也作为 token 序列”的核心思想。
- 区分机器人轨迹数据与视觉语言网络数据的联合/共微调作用。
- 设计一个不泄漏答案的泛化评估。

## 2. 今日知识点及其在 VLA 中的作用

RT-2 把 VLM 的语义先验与机器人控制连接起来；它提醒我们评估的不只是见过任务拟合，还包括语义与物体关系的迁移。

## 3. 必要概念、公式与数据流

- 抽象目标：对混合数据最大化条件 token 的对数似然，机器人样本预测动作 token，VQA/描述样本预测文本 token；不同样本使用不同输出语义和 loss mask。
- 机器人动作序列仍需可逆映射 `token ↔ normalized action ↔ physical action`，语言词表中的编号不能脱离 action tokenizer 解释。
- “出现新物体”不等于组合泛化；训练/测试切分必须记录物体、指令模板、关系与场景是否重叠。

## 4. 分步骤学习内容

1. 用自己的话比较 RT-1 与 RT-2 的训练信号。
2. 画出两类 batch 进入同一模型、分别计算 loss mask 的示意图。
3. 为“把可回收物放入正确容器”设计 ID、未见物体和未见组合三组测试。
4. 列出可能的数据泄漏，并给每项一个检查方法。

| 项目 | 内容 |

| 输入 | 训练含红/蓝方块和纸杯；测试候选包含新颜色方块、易拉罐及见过物体的新指令组合。 |

## 9. 常见错误与排查提示

- 将共微调误写为只有机器人数据。
- 把新句式当作新技能。
- 未区分语义迁移和控制精度。
- 若输出与预期不符，先打印 episode/step 索引、shape、dtype、单位和 dataset key，再检查模型。
- 不得把论文中的报告结果或本页“预期输出”写成本地实测。

## 1. 今日目标与预计时间

预计：**100–140 分钟**。

- 区分原始动作、统一语义动作、归一化动作和部署动作。
- 为两种控制模式定义可审计转换。
- 识别不可无损转换的本体差异。

## 2. 今日知识点及其在 VLA 中的作用

跨本体训练的关键不是把数组补成同样长度，而是让每一维在物理意义、坐标系与尺度上可比较，并确保部署时可逆。

## 3. 必要概念、公式与数据流

- 推荐显式管线：`raw action → frame/unit/control conversion → canonical action → normalize → model → denormalize → embodiment controller`。
- 统一示例可用 `[Δx,Δy,Δz,Δr_x,Δr_y,Δr_z,g]`，但关节速度到末端增量需雅可比与时间步，未提供机器人模型时不能伪称可精确转换。
- 逐维 percentile 归一化示例：`z=2(a-p01)/(p99-p01)-1`，常量维需 mask/epsilon；统计必须按 dataset/embodiment key 保存。

## 4. 分步骤学习内容

1. 为本体 A 写 base-frame cm 到 m 的转换。
2. 为本体 B 写 tool-frame delta 到 base-frame 的旋转映射，仅用符号表达也可。
3. 列出关节速度转末端增量所需信息和不可识别条件。
4. 用小数组计算 percentile 归一化与反归一化闭环误差。

## 5. 必做作业

- 提交 `action_contract.md`，包含 7 维语义、单位、frame、正方向、频率和 gripper 编码。
- 实现 `normalize/denormalize`，测试常量维和越界值。
- 写一份不可转换字段清单及采用 mask/分头/拒绝接入的决策。

## 6. 作业输入、预期输出与验证方法

| 项目 | 内容 |
|---|---|
| 输入 | A 的平移单位 cm、base frame；B 的平移单位 m、tool frame；统计 `p01=[-0.1]*6+[0]`、`p99=[0.1]*6+[1]`。 |
| 预期输出 | A/B 转换后明确落到同一 canonical frame；归一化再反归一化对区间内样例误差小于 `1e-6`；常量维不会除零。 |
| 验证方法 | 逐维打印名称、单位、frame、范围。；断言 round-trip 误差。；人工核对 gripper 的 0/1 含义在训练和控制端一致。 |

预期输出只有在实际运行并保留证据后才能改写为“实测通过”。

## 8. 评分与验收标准

## 9. 常见错误与排查提示

- 旋转向量与欧拉角直接逐维相加。
- 不同频率下复用 delta action。
- 对 padding 维也计算 loss。
- 若输出与预期不符，先打印 episode/step 索引、shape、dtype、单位和 dataset key，再检查模型。
- 不得把论文中的报告结果或本页“预期输出”写成本地实测。

## 10. 时间不足时的最低完成线

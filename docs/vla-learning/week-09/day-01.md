## 2. 今日知识点及其在 VLA 中的作用

RT-1 展示了把机器人策略扩展为大规模序列模型的基础范式；理解动作离散化能帮助你判断 token 策略的精度、吞吐与安全边界。

## 3. 必要概念、公式与数据流

- 抽象数据流：`RGB [B,T,3,H,W] + instruction [B,L] → visual/language tokens → policy → action bins [B,T,D_a]`。
- 每个连续动作维度可按区间 `[m_j,M_j]` 分成 `K` 个箱：`q_j=clip(round((a_j-m_j)/(M_j-m_j)*(K-1)),0,K-1)`；解码得到箱中心，存在量化误差。
- RT-1 的工程启示是高维视觉 token 压缩、语言条件化与动作 token 预测；论文结构细节要与作者原图核对，不把抽象图误当唯一实现。

## 6. 作业输入、预期输出与验证方法

| 项目 | 内容 |
|---|---|
| 输入 | 动作范围 `[-1,1]`，`K=8`，样例动作 `[-1,-0.2,0.6,1,1.2]`；允许纯 Python list。 |
| 预期输出 | 数据流图含 `[B,T,3,H,W]`、`[B,L]`、`[B,T,D_a]`；代码输出 bin 均在 `[0,7]`，解码误差不超过半个箱宽（裁剪样例另行说明）。 |
| 验证方法 | 断言 bin 的 dtype/范围正确。；断言区间内样例 `abs(decoded-clipped) <= (M-m)/(2*(K-1)) + 1e-6`。；人工检查图中语言确实影响动作，而不是只接到说明文字。 |

预期输出只有在实际运行并保留证据后才能改写为“实测通过”。

## 9. 常见错误与排查提示

- 混淆时间 token 与动作维度。
- 用同一全局范围量化所有维度，却未说明不同单位。
- 只比较训练准确率，不估计解码误差。
- 若输出与预期不符，先打印 episode/step 索引、shape、dtype、单位和 dataset key，再检查模型。
- 不得把论文中的报告结果或本页“预期输出”写成本地实测。

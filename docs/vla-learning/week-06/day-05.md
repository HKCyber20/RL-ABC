## 1. 今日目标与预计时间

预计 90–120 分钟。实现可复现、只作用于训练集的安全增强，判断颜色/空间变换是否改变任务语义或动作标签。

## 2. 这在 VLA 中的作用

增强可缓解背景、亮度和小位移过拟合，但 VLA 的图像与动作存在几何对应。随意水平翻转或改变指令关键颜色，可能把正确动作变成错误标签。

## 3. 核心概念与数据流

训练时 `I'=g(I;ξ)`，若变换不改变控制语义则标签保持 `a'=a`；若是几何等变变换，必须有一致的 `a'=T_g(a)`。例如以相机横轴为基准的水平镜像可能要求 `Δx'=-Δx`，但只有坐标约定明确时才成立。

```text
train: raw → stochastic augment → fixed normalize
val/test/rollout: raw → fixed normalize
```

## 4. 分步学习

1. 把增强分为光度、裁剪/平移、镜像/旋转和遮挡。
2. 对每项写“是否保留指令语义、是否需改动作、风险”。
3. 先启用轻微亮度/对比度和小裁剪；颜色是指令条件时禁用改变类别的 hue shift。
4. 固定 augment seed，保存同一帧的 8 个样本与参数。
5. 确认 val/test 不经过随机增强；对 batch 做 shape/finite 检查。

## 5. 必做作业

- 完成增强安全矩阵，至少分析 6 种变换。
- 实现 2 种安全增强并可通过开关完全关闭。
- 做标签一致性测试：安全增强动作不变；若选择镜像，必须同步变换动作并验证两次镜像恢复原样。

## 6. 输入、预期输出与验证

输入：16 帧训练图像及其 action/instruction；固定增强 seed；验证集 8 帧。

预期输出：训练增强样本内容变化但 shape/dtype 合规；相同 seed 输出相同；验证集重复读取逐像素相同；关键颜色仍可辨。均为预期结果。

验证：计算增强前后像素差；确认 instruction 与 action 的变化规则；运行 train/val transform 配置审计；用极端增强负向样例展示为什么不安全。

## 8. 评分与验收

- 安全矩阵联系坐标与指令：25 分。
- 两种增强实现可开关：20 分。
- 样例和确定性证据：15 分。
- 标签/几何一致性验证：25 分。
- val/test 审计与自测：15 分。

总分 100，80 分通过；改变关键颜色而指令不变、空间变换不同步动作或验证集随机增强时不通过。

## 9. 常见错误与排查

| 错误 | 排查 |
|---|---|
| crop 把目标完全裁掉 | 加目标可见率检查或减小范围 |
| hue jitter 改变“红/蓝” | 颜色条件任务只做保色光度变换 |
| transform 顺序错误 | 先几何/光度，再 tensor normalize，并记录参数 |
| 每个 worker 随机性失控 | 设置 worker seed 并记录 generator |

## 10. 时间不足时的最低完成线

使用 CPU 和 16 张 synthetic 任务图像，只实现小范围亮度和随机平移/裁剪中的一种安全方案，完成 6 类安全矩阵与 val 无随机增强检查。

## 11. 可选提高

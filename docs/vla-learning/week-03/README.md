## 本周核心能力

本周学习将专家 episode 转换成监督样本，训练 `observation/state -> action` 行为克隆策略，并用闭环 rollout 而非仅用训练 loss 评价。它对应总 Goal 中“构造数据、训练并闭环评估策略”的第一条完整低维基线，也为后续加入图像和语言建立可靠实验方法。

## 前置知识

- 第 1 周的 batch、模型输出与 loss/backward；
- 第 2 周的动作定义、单位、坐标系和控制频率；
- Python 与基础 PyTorch；若无 PyTorch，可用 NumPy 实现线性/规则基线并完成全部数据与评估概念；
- 不需要 GPU、仿真器或外部数据。

## 本周代码与实验产物

- episode schema 与时间索引图；
- 可检查长度、形状和时间对齐的 BC Dataset；
- 动作归一化统计、分维损失和反归一化测试；
- 按 episode/场景无泄漏划分及审计报告；
- 教师分布与策略分布的协变量偏移实验；
- 至少 20 次确定性或带 seed 的 rollout 指标与失败表；
- 可从干净环境复跑的低维 BC 周项目。

## 必做与可选任务

必做是数据契约、按 episode 划分、训练曲线、闭环指标和失败分析。可选包括 DAgger 思考、bootstrap 置信区间。低资源方案使用一维/二维点质量环境和数百个数值样本，CPU 数分钟内即可完成；无深度学习框架时使用线性最小二乘或手写小模型，核心评估不变。

## 最低完成线

- 明确 `o_t,s_t,a_t,o_{t+1}` 的时间关系；
- 数据集样本、归一化和划分通过断言；
- 一个可学习的状态到动作基线具有训练/验证证据；
- 至少 20 次 rollout，报告成功率、最终误差和失败类型；
- 能用自己的实验解释低 validation loss 不保证闭环成功。

## 周末测验、周项目与通过标准

Day 7 周测 25 分、项目 75 分；总分 80 分通过。时间对齐、无 episode 泄漏、动作反归一化、闭环成功率四项为门槛。成功率不设人为最低百分比，因为学习目标是实验完整性；若策略失败，也可凭可靠复现与诊断通过，但不能把失败伪装成成功。

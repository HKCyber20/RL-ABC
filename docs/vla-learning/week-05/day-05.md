## 1. 今日目标与预计时间

预计 90–120 分钟。把“抓取并放置成功”变成可执行、抗瞬时抖动的判定器，并拆出到达、抓住、抬起、放入四个阶段指标。

## 2. 这在 VLA 中的作用

训练 loss 衡量动作拟合，成功判定才衡量任务。含糊或有漏洞的 success 会直接污染数据筛选、rollout 指标和失败分析。

## 3. 核心概念与公式

设物体位置 `p_o`、目标中心 `p_g`、目标容差 `ε`，基础空间条件为：

\[
c_{inside}=\|p_o-p_g\|_2<\epsilon.
\]

稳定成功可定义为 `inside ∧ released ∧ stable` 连续满足 `K` 帧；抓取可结合双指接触、夹爪闭合与物体随末端移动。阶段状态机：

```text
approach → grasp → lift → transport → release → stable_success
```

## 4. 分步学习

1. 写出任务成功与任务失败的物理语义，避免使用奖励阈值代替定义。
2. 定义每个阶段的可观测谓词与阈值单位。
3. 引入连续 `K` 帧稳定性和超时规则。
4. 构造正常成功、掠过目标、抓后掉落、未松爪、边界抖动五种序列。
5. 运行判定器并输出首次达到每个阶段的时间步。

## 5. 必做作业

- 编写 `success.py` 或等价伪环境判定器，返回 `is_success` 与阶段字典。
- 创建五种合成状态序列测试，至少包含一个“瞬时满足但最终失败”的反例。
- 写一张阶段指标表：公式、阈值、单位、所需传感器和可能误判。

## 6. 输入、预期输出与验证

输入：长度 20 的状态序列；可设 `ε=0.05 m`、稳定帧 `K=3`；Mock 用二维欧氏距离。

预期输出：正常序列仅在连续 3 帧满足后成功；掠过、掉落、未松爪、抖动序列失败，并给出最远阶段。数值是教学配置，结果需实际运行验证。

验证：五个测试均有精确期望；改变 `K` 和 `ε` 后记录判定敏感性；success 只能从 `False→True` 一次，或明确说明可逆设计。

## 8. 评分与验收

- 成功条件物理语义完整：20 分。
- 阶段指标可执行：20 分。
- 稳定性与超时处理：15 分。
- 五个测试含反例并通过：30 分。
- 敏感性和自测：15 分。

总分 100，80 分通过；把 `reward>阈值` 或 episode 结束直接当成功时不通过。

## 9. 常见错误与排查

| 错误 | 排查 |
|---|---|
| 物体途经目标即成功 | 要求释放并连续稳定 K 帧 |
| 接触等同抓住 | 检查闭合、双侧接触和随动 |
| 阈值无单位 | 名称与表格同时写 m/rad/frame |
| 只存最终 success | 同时存阶段首次达到时间，便于定位失败 |

## 10. 时间不足时的最低完成线

在二维 Mock 上实现 inside、released、稳定 3 帧，并通过正常、掠过、未松爪三种序列。

## 11. 可选提高

用物体包围盒与容器几何替代中心距离；绘制阶段转移时间线；评估阈值变化对成功率的影响。

## 12. 完成后的自测题

1. 为什么“物体中心在目标内”未必等于成功？
2. 阶段指标如何帮助区别策略失败和控制失败？
3. 稳定帧 K 太大或太小分别有什么后果？
4. 任务奖励和评估成功条件应如何分工？
